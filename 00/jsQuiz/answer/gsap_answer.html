GSAP 정답 예시 (해설 포함)

GSAP(GreenSock Animation Platform) 퀴즈입니다. 총 14문제이고, 난이도는 아래로 갈수록 올라갑니다.
풀이 방법: 각 문제의 // 여기에 작성 아래에 GSAP 코드를 쓰세요. GSAP 애니메이션은 시간이 걸리기 때문에, 채점 코드가 애니메이션을 끝 지점으로 순간이동 (tween.progress(1)) 시킨 뒤 값을 확인합니다. 그래서 대부분의 문제에서 만든 tween/timeline 을 지정된 변수에 꼭 저장해야 합니다. (예: tweenTo = gsap.to(...))
규칙: ① check(...) 와 "(수정하지 마세요)" 코드는 건드리지 않습니다. ② 문제 10, 12 는 실제 시간이 지난 뒤 채점되므로 결과가 조금 늦게 나타납니다. ③ 막히면 각 문제의 "힌트"를 먼저 읽어 보세요.
